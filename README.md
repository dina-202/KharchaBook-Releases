# KharchaBook Releases

Official public update channel for KharchaBook Android.

- [Download the latest signed APK](https://raw.githubusercontent.com/dina-202/KharchaBook-Releases/updates/KharchaBook-latest.apk)
- [`latest.json`](https://raw.githubusercontent.com/dina-202/KharchaBook-Releases/updates/latest.json) contains the version, build number, release notes, and SHA-256 checksum used by the in-app updater.

Only compiled release files are published here. The application source, signing key, passwords, and private project history are not included.

Android may ask you to allow installs from KharchaBook and confirm the update. Every APK must pass the checksum check and Android's signing-certificate verification before it can replace an installed version.
