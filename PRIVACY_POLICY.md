# KharchaBook Privacy Policy

**Effective date:** 24 September 2026

KharchaBook is an offline personal expense tracker. It does not require an account and does not collect, sell, share, or transmit personal information.

## Data stored on the device

Expense records, milk entries, custom categories, vehicles, recharge types, settings, and PIN-lock configuration are stored locally on the user's Android device.

## Network access

KharchaBook does not use advertising, analytics, cloud storage, user accounts, or remote APIs that receive personal data. The Google Play edition relies on Google Play for application updates and does not request internet access itself.

The direct-download edition can connect to the official KharchaBook GitHub release channel to check for application updates and download an APK only after the user approves the update. These requests contain ordinary network metadata handled by GitHub, such as the device IP address and user-agent string. Expense records and other user-created data are never included. Downloaded APKs must come from the pinned release repository and pass the published SHA-256 integrity check before installation is offered.

## Files and backups

When the user chooses an export or backup action, KharchaBook writes the requested PDF, Excel, or JSON file to the device's Downloads/KharchaBook directory. When restoring a backup, the user explicitly selects a JSON file through Android's file picker.

## PIN lock

The optional four-digit PIN is stored as a one-way hash. KharchaBook cannot recover a forgotten PIN.

## Deleting data

Users can delete individual records and eligible categories inside the app. Uninstalling KharchaBook removes its private local database, subject to Android's device-backup settings. Files explicitly exported to Downloads remain until the user deletes them.

## Changes

Material privacy-policy changes will be documented with a new effective date and included with the relevant app release.

## Contact

Privacy questions can be sent to the app publisher through the support contact listed on the Google Play or official distribution page.
